# DeConfuserEx-tools

A collection of utilities to unprotect and deobfuscate applications protected with **ConfuserEx**.

---

> ⚠️ **Antivirus Warning:** All files in this repository are **100% clean and malware-free**. However, antivirus software may flag them as **false positives** due to how unpackers and reverse-engineering tools interact with executable code. You may need to add an exclusion rule in your security software to run them.
